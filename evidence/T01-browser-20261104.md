## 真实浏览器状态

`python3 -m http.server 18080 --bind 127.0.0.1 --directory browser-spike` 在绑定本地 HTTP 端口时返回 `PermissionError: [Errno 1] Operation not permitted`。使用本机 Chrome 和 Puppeteer Core 运行真实浏览器脚本，失败发生在 Chrome 子进程启动阶段，未导航到探针。此环境未获得真实浏览器冷启动、热启动或评估耗时。

| 验收项 | 结果 |
| --- | --- |
| 真实 Chrome 同源 Worker 初始化和三样例 | NOT_RUN |
| 真实浏览器挑战移动、撤销、重置、达标剩余事项 | NOT_RUN |
| 加载失败后原页重建 Worker 并重新评估 | NOT_RUN |
| Chrome 冷/热启动、热评估计时 | NOT_RUN |
| 目标托管匿名 HTTPS、子路径、iframe、WASM、Worker MIME | NOT_RUN，入口待确认 |

在可启动本地 HTTP 和 Chrome 的环境按[探针说明](../browser-spike/README.md)运行 `scripts/check_browser_spike.mjs`。浏览器脚本检查三样例、挑战进度和覆盖、恢复及 MIME，并输出实测时长。脚本语法检查通过。目标入口获得授权后，用匿名会话对实际子路径重复执行。
