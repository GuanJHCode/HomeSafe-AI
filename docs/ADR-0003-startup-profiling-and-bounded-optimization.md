# ADR-0003：保留启动剖析与模型拆分，停止本轮轻入口实验

日期：2026-11-04。状态：**已决定并执行：PR-3 撤回独立通过，最终 enforce 仍失败**。本地提交见最终交付回执；本轮无远端写入。本文不授权推送、部署或架构变更。

## 决策

保留经独立审查的 PR-1 启动剖析、PR-2 canonical 模型职责拆分，以及 CI 功能/严格性能分步、失败清理和证据归档。舍弃 PR-3 轻入口/提前启动唯一 Worker 候选，已按冻结的 PR-2 源码与分发精确回退，28 个分发文件逐字节一致并独立验证。候选原始补丁、生命周期反例、独立 BFCache 和功能结果作为 **DISCARDED 实验历史**保存，不记作最终产品能力。

T07 冷首次可编辑 p95 <=3000 ms 仍 OPEN_NOT_MET；冷规则 <=12000 ms、热评估 p95 <=150 ms 和真实编辑/哈希验证保持不变。本轮已有受控正确性和收益证据后，不再追加重跑挑选更快结果，不擅自扩建定制 Python/WASM、切换后台或放宽门槛，也不重做已否决的 defer_build 实验。后续优先在新源码提交获得推送授权后，执行预先固定的 CI 验证方案，保留全部结果；当前新远端 CI 尚未运行。

## 依据与取舍

PR-2 相对同样带 PR-1 trace 的基线，五对全部改善，配对节省中位数 334.4 ms，通过预先规定的至少 4/5 改善且中位数 >=100 ms；独立正确性与实际 Pyodide ZIP 闭包也通过，因此采纳。随后完整 enforce 的冷 p95 为 3858.5 ms，仍失败；不能将“有收益”写成“目标达成”。[独立 PR-2 结论](../evidence/REVIEW_STARTUP_PR2_20261104.md)。

PR-3 在修复生命周期反例后通过候选功能检查，但固定 AB/BA/AB/BA/AB 仅 **3/5 改善，中位节省 43.9 ms**，未满足采纳标准。A/B 冷首次可编辑 p95 为 **3946.1/4311.6 ms**；十次实际编辑和对内哈希一致。舍弃依据是预注册收益门槛失败，不是用功能 PASS 掩盖性能，也不是仅因尚未达到 3 秒。候选完整 hot/enforce 没有运行，不能把 PR-2 的 12.5 ms 热值移植给 PR-3。[实验审计](../evidence/REVIEW_STARTUP_BENCHMARK_20261104.md)。

同批 PR-3 配对中，Worker 创建与 init 发送分别提前的中位数约 114.8/115.3 ms，init 收到仅提前约 34.4 ms；实际可编辑节省中位数 43.9 ms。load_pyodide、pydantic_import、canonical_import 的 A−B 阶段中位差约 −20.7、−28.3、−77.1 ms，负数表示候选该阶段更慢。**这些不同指标的中位数不能相加构造总耗时**。数据说明更早创建 Worker 没有转化为足够可靠的端到端收益；CPU 竞争是待验证解释，不能视为已证明原因。

PR-1 tracing 的另一个独立 overhead 实验也不作优化结论：B−A 中位 −278.9 ms、范围 −850.9 至 +217.5 ms；小样本波动不能证明 tracing 提速、开销为零或最大成本已知。

## 当前诊断与下一步

在最终保留 PR-2 的唯一还原后 enforce **同一个冷 trial 2**（首次可编辑 4086.1 ms）中，测得 load_pyodide 2725.1 ms、Pydantic import 151.6 ms、canonical import 573.0 ms、首评 60.3 ms；Worker 内初始化 wall 3467.2 ms，已测并行区间并集 3466.2 ms，未归因残差约 1.0 ms。core fetch/hash 等阶段与运行时启动重叠，以上阶段不再相加生成新总数。load_pyodide 包含解释器启动和预加载等工作；canonical import 包含类/schema 及模块导入，当前 trace 没有进一步孤立纯 schema 成本，不能把全部时间称为编译。

这些是可继续定位的实测阶段，不是“已无优化空间”或“必然无法达到 3 秒”的证明。原 enforce 与 trace 保持可复查，下一步在明确环境和固定提交上验证：公开 CI 的 Chrome 156 与本地 Chrome 154 数字不能直接相减归因于代码。若需更换运行时、权威计算架构或指标，必须另行形成有证据的提案并取得用户决定。

最终唯一 enforce 实际退出 1：冷样本 3913.5、4086.1、3784.6、3843.3、4049.8 ms，p50 3913.5 ms、p95 4086.1 ms；冷规则通过 12000 ms，热评估 p95 12.6 ms 通过 150 ms。此前 3858.5/12.5 回执保留为先前 PR-2 阶段，不覆盖也不相减推导优化。[最终原始回执](../evidence/startup-benchmark/final-retained-enforce-performance.json)与[独立审计](../evidence/startup-benchmark/independent-final-retained-enforce-review.json)已归档。最终还原验证、原始证据及所有版本范围见[本轮阶段记录](../evidence/STARTUP_ADJUSTMENTS_20261104.md)。真实资产、权利、公开托管、另一网络及跨浏览器验收仍是独立缺口，不由本 ADR 或占位场景性能实验关闭。
