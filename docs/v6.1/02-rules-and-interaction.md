# 规则、交互与挑战

## 八条教学规则

| 规则 | 检查内容 | 解释边界 |
| --- | --- | --- |
| R001 | 窗边支点关系 | 距离为教学配置，不是行为预测 |
| R002 | 窗口防护自报 | 未确认信息保留待核查 |
| R003 | 柜体固定自报 | 外观和类别不能证明固定 |
| R004 | 危险品收纳高度/锁状态 | 依赖观察资料及能力配置 |
| R005 | 指定通道占用 | 不输出真实最小净宽或无障碍认证 |
| R006 | 通道地毯固定 | 固定情况与几何位置分开处理 |
| R007 | 可接触线缆收纳 | 不从模型外观推断真实整理状态 |
| R008 | 通道门栏底框 | 不证明儿童隔离有效 |

不为剧情增加门栏隔离规则；区域拓扑、覆盖、开启与安装状态未建模时不能推出隔离有效结论。

## 状态、覆盖与几何

主要结果为 triggered、needs_review、not_triggered。目标缺失或不适用不等于通过；缺角色、缺路线、缺资料必须在覆盖说明中展示。

已知 true 的 trait 参与，已知 false 不参与；未知但类别提示相关时只进入未确认候选，其余未知进入资料与覆盖。每对象合并为一张 SetupItem 卡，避免关系组合造成重复危险卡。coverage.pending_count 是覆盖指标，不直接当风险数量。

使用二维旋转包围盒、SAT 相交及垂直区间校验；边界接触与实体内部穿透采用不同策略。禁止实体互穿、越界、悬浮和不一致支撑高度。

| 错误 code | 界面行为 |
| --- | --- |
| SOLID_PENETRATION | 高亮相交对象并回弹 |
| FOOTPRINT_OUTSIDE_ROOM | 高亮边界并回弹 |
| HEIGHT_OUTSIDE_CONTAINER | 指向相关高度字段 |
| FLOOR_OBJECT_FLOATING | 提示悬浮并回弹 |

## 比较来源

| 变化 | 展示语义 |
| --- | --- |
| triggered → not_triggered | 本条件不再触发，不等于全屋安全 |
| needs_review → not_triggered | resolved_unknown：资料已补充，未必空间整改 |
| needs_review → triggered | new_triggered：新确认触发条件 |
| 删除对象 | removed_from_scope，不宣称现实问题消失 |
| 改路线、成员、阈值、traits 或尺寸 | 重建基线、退出原挑战 |

layout_hash 与 observation_hash 区分挪动和补资料，混合变化明确说明。

## 三段体验与成功定义

1. 引导：窗边椅子，学习选择、移动、撤销与未知提示。
2. 主挑战：书柜/储物架有多个合法摆位，部分压缩指定通道，呈现两类需求取舍。
3. 自由演练：改布局并导出解释；补资料进入独立模式，不计原挑战成功。

公开挑战锁定成员、路线、traits、尺寸、阈值与目标，仅允许白名单家具移动/旋转。合法且实际变化的提交计一步；无变化和轮询不计；非法尝试回弹并单独计数。冲突只在一方目标条件减少而另一方新增触发时记事件，不能每次刷新累计。

成功必须满足目标集合中每条规则仍存在且均为 not_triggered；同时报告剩余已触发、待核查和未覆盖项。计数缺失就显示不可用，不默认零。V6 历史诊断达标后仍有 2 项触发、4 项待核查；这只是该样例结果，不能硬编码给所有场景。

至少三种合法布局验证机制，不仅切换 before/conflict/improved。相机高度不联动触及高度。没有全屋安全分、事故概率或排行榜。清单区分模拟变化、需补资料和现场核查。
