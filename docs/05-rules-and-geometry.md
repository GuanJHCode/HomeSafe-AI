# 05｜规则、噪声控制与挑战边界
## 八条规则
R001窗边支点关系；R002窗口防护自报；R003柜体固定自报；
R004危险品收纳高度/锁状态；R005指定通道占用；R006通道地毯固定；
R007可接触线缆收纳；R008通道门栏底框。
每条均独立类，在rules.py注册；同对象可同时适用多规则。

## V6待核查项降噪
V5把所有unknown trait都加入候选，R001造成笛卡尔积。
V6：明确true参与；明确false不参与；未知且类别有相应提示时作为**未确认候选**；其余未知进入对象资料与Coverage。
不会自动补false，也不将类别提示写成实测事实。每个未知对象只有一张SetupItem资料卡。
界面不得把coverage.pending_count合计成风险数量；该字段包括关系待核查和特征未确认，是覆盖指标。
“确认建议”必须预览逐项变更、来源设user_reported/demo/simulated，不能默默批量点掉未知。
改变未知候选类别/trait时需rebaseline，不能拿评估范围缩小充当整改。

## 几何
沿用米制、正Y、底面中心；二维OBB边界距离与SAT相交，垂直区间阻止实体互穿。
用于通道关注的边界接触与用于家具摆放的内部穿透是不同策略。
指定矩形路线x/z为中心，P0不做任意多边形通道、不声称最小净宽。
窗边距离0.6m、reach高度等仅教学参数，真实规范和人体能力不能由它们推导。

## 比较
not_triggered≠安全；triggered→not_triggered是“本条件不再触发”；
needs_review→not_triggered新增resolved_unknown，标“资料已确认/补充”，未必现实整改；
needs_review→triggered正常显示new_triggered；
删除对象removed_from_scope；改路线/成员/阈值/trait需要重建基线。
layout_hash与observation_hash区分挪家具和勾选属性；challenge禁止修改后者。

## 不新增门栏儿童隔离规则
R008仅覆盖老年通道底框。它不能单独证明门栏对儿童有效。
用户建议的“为儿童装门栏→老人受影响”可作为未来故事，但需要区域拓扑、门栏覆盖/开启状态/安装信息等，首版不为剧情扩充未经验证的R009。
优先把窗边书柜/储物架挪动到狭窄路径的**合法备选位置**做高级关卡；不刻意把椅子塞到通道中心作为唯一有趣机制。

## 内容与可用性
真实安全知识与演示阈值继续分离；规则来源审核未完成保持pending。
不以“不存在finding”证明不存在风险；没有路线/没有角色/未知对象的覆盖说明继续展示。
