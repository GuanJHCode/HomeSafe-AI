## 功能验收重点

| 检查 | 应观察到的行为 |
| --- | --- |
| 旋转占地 | 旋转后的角点、占地相交与距离计算符合已确定的坐标约定 |
| 窗边椅子 | 规则根据已定义输入触发，并给出涉及对象与依据 |
| 未知窗口防护/柜体固定 | 产生 `needs_review`，不因缺数据而判安全 |
| 移动后重算 | 新快照形成新版本，显示对应版本的结果 |
| 请求乱序 | 较早请求晚返回，不能覆盖当前版本结果 |
| 老人指定通道 | 椅子新位置占用通道时显示冲突；再次调整后结果可比较 |
| 删除对象 | 差异解释为移出范围或输入改变，不自动宣称现实风险解决 |
| 视觉模型替换 | 不改变稳定对象标识、已确认尺寸、规则关联与历史 |
| 报告导出 | 包含场景/规则版本、输入依据、未知项、整改变化与局限 |
| 可选生成 | 创建超时不盲目重发；重启恢复任务；持久化结果；预算可对账 |

实现八条规则后，每条至少补齐适用、触发、不触发、输入缺失和几何边界样例；阈值依据必须可追溯。这是本次新增的验收建议，未声称已有对应测试。
