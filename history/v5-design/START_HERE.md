## 开工前仅有的人工准备

核对3300积分的实际余额、到期时间和当前扣费；在Lux3D网页先做椅子/柜子小样，下载原始GLB，保留脱敏生成证据。没有API Key不阻塞开发。真人照片和控制台原图放到仓库外私有目录。

## 上传Git：选一种方式

**全新空仓库**：使用本包作为初始目录，先查看 `.gitignore` 和精确文件清单；由你自行初始化、提交并推送新分支。不要替你虚构Git姓名/邮箱。

**远仓已有内容**：先clone到另一个目录，禁止把ZIP直接覆盖已有仓库。预览：

```bash
python scripts/export_sources.py
```

确认清单后导出到独立目录：

```bash
python scripts/export_sources.py --dest /你的路径/HomeSafe-AI --ack-reviewed-files
```

已有同名但不同内容会停止，需人工合并。导出工具不push、不删除文件、不改变远仓历史。

`package-manifest.json` 校验的是本次原始交接快照。开发后文件变化导致快照检查失败是正常的；不能偷偷更新哈希冒充本次已审查。后续靠Git提交、PR审核、CI维护新版本，不将旧包哈希用作永不改变的开发门槛。
