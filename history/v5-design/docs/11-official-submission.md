# 11｜从开发到官方最终提交

## 准备材料

报告：目标人群、范围、实际流程、Lux3D生成/失败迭代与资产证据、架构/规则、测试、局限/隐私/许可、复现入口。
Demo：真实应用实录（建议3–4分钟，不是官方限制）；可选在线体验。源码附锁文件、启动步骤、样例和合法资产获取方法。
传播：按当前中文官方指定话题发布真实项目，未实现的功能不要宣传。[S1]

推荐视频：问题介绍→Lux3D资产生成记录/导入→儿童检查→移椅子引出老人通道问题→再次调整→独立unknown仍存在→行动清单。视频来自程序运行，LuxReal非必要。

## 发布状态

IMPLEMENTATION_BASELINE：当前包状态，可开工。
READY_FOR_SUBMISSION：产品/材料通过本地技术检查与本人内容、权限审核。
SUBMITTED：官网有明确最终提交回执。
ACCEPTED/SHORTLISTED/WON：只能据官方后续通知。

## 正式操作

1. 本人登录核对团队、授权、表单格式/体积/时长和截止。未获得完整登录条款，不能声称已全部同意。
2. 冻结最终产品commit，重跑测试；生成模型/素材清单，锁定合法分发范围。
3. 录实机视频、完成报告；材料版本与代码版本分别记录，以source_commit关联，不制造“文件自包含自身hash/commit”的循环。
4. 用`check_submission.py`及人工清单验证；当前DRAFT应失败，不能把模板改true蒙混过关。
5. 上传报告与视频或有效Demo；源码和模型包按允许范围提供；私有仓库确认评委访问方式。
6. 检查附件可下载、视频可播、匿名链接可用；最终点击提交不是仅保存草稿。
7. 记录作品编号、实际时间、附件列表和脱敏回执，再重新打开查看状态。
