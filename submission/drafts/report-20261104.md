状态：DRAFT_NOT_SUBMITTABLE。核对基线：`57faf384d64e9770407b28086fdfeb5b193a6d6f`，分支 `codex/v6.1-browser-3d`。续作改动未冻结；本稿不能作为最终版本报告或验收回执。最终报告必须绑定验收后的源码提交、场景 hash、规则版本、分发清单和真实视频。

## 问题与受众

本项目供成年照护者在合成客厅里练习空间取舍。一个家具调整可能消除儿童窗边支点条件，同时占用老人指定通道；练习的价值在于理解变化和核查依据。它不接收家庭照片，不测绘住宅，不预测事故，也不提供安全认证。

## 玩法与已存在的实现

浏览器中选择儿童或老人观察视角，检查条件卡，选择并移动或旋转允许的家具。合法摆放交由 Python 校验及重新评估；非法操作回弹。已有基线支持撤销、重做、重置、椅子引导挑战、JSON 行动清单与打印。选择视角不更改角色能力，两角色检查保留。本轮已补齐柜体主挑战、三段入口、检查卡聚焦/覆盖展示和布局导出一致性；主挑战至少三种合法布局、非法反例及两角色取舍已通过独立审查和隔离浏览器验证。代码与完整运行证据仍以最终汇总为准，当前未冻结参赛版本。

挑战达标只代表目标集合达到本关条件。仍显示实际触发、待核查和未覆盖内容；未知不是 false，资料补充不算布局整改，missing/not_applicable 不是挑战通过。模型尺寸是合成样例中的业务尺寸，不是现实实测。

## 技术实现

Vue 3 / TypeScript / Three.js 管理交互及渲染。同源 module Worker 运行官方 Pyodide 314.0.6 和 Pydantic 2.12.5，加载同一 Python 核心；TypeScript 不另写规则。canonical 模型生成契约。评估、比较、挑战计数与胜负以 Python 为唯一来源；结果绑定 scene revision、input hash 和 ruleset。网页没有账号、数据库、收费生成入口或 API Key。

模型清单经过来源、哈希和许可暂存门禁。原件与优化件必须分开记录，模型失败时显示占位状态。构建保留固定 runtime、wheel、Python bundle、资产和许可证通知的摘要，部署校验核对实际上传字节。

本轮最终复测：原生测试260项、应用27项、探针及输入工具JS18项通过；严格类型检查、含25文件的构建校验、8项包检查通过。本子项许可证/暂存/导出53项针对性测试属于相关测试覆盖，不另加到全量数。详见 [本轮汇总](../../evidence/CONTINUATION_20261104.md)。主挑战和体验补缺的独立审查及隔离 Chrome 154 localhost 浏览器流程通过。

隔离 Chrome 154 localhost 性能实测，nearest-rank p95：5次冷启动3725ms；5次首个画布/视角按钮可观察界面507ms（不代表家具编辑就绪）；5次缓存后重载3676ms；三次预热后30次热评估10.3ms。原始样本见 [性能回执](../../evidence/browser-performance-20261104.json)，独立复核见 [浏览器探针审查](../../evidence/REVIEW_BROWSER_PROBES_20261104.md)。样本量和范围不足以推断正式公网性能。主任务另保存24.44秒真实开发回归录屏（6,894,533字节），来自独立审查后的应用逻辑和计数标签版本，实际流程回执 PASS；它是开发证据，不是3–4分钟同版最终参赛视频。报告引用数字以主任务实测回执为准。

正式 HTTPS、另一网络、Safari/Edge 实际设备、真实模型视觉和交互、冻结版本性能尚需对应证据。工程目标为首个可操作界面≤3秒、规则冷启动≤12秒、热评估 p95≤150ms；不能以单点 localhost 结果推断公网达标。没有进行用户试玩，不报告满意率、事故率或效果提升。
