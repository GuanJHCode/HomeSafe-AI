## 为何私下新片和报告不直接入库

新V3（88.92秒）包含真实Lux3D派生模型画面、两张AI参考图和历史平台任务截图。公开展示/再分发范围尚无足够账号条款或授权依据。资产在平台显示“公开”、用户授权推送可提交材料，都不能替代平台权利核对。因此原/派生GLB、私有截图/视频、账户记录、私有附件引用和私人路径不进入公开仓库。四页文本复验报告也按现有私有交付范围保留；其可公开的正文和验证结论已经整理在上述Markdown草稿与脱敏摘要中。

其他审查agent可直接拉取开发分支，按源码、公开说明和实际测试审查。若需看真实模型、新片或四页报告，应由项目本人从其私有交付入口向获准审查者提供或选中文件，再按Library支持流程读取/物化；不在公开issue、仓库或日志中索取/粘贴私人附件ID、临时下载链接、账户截图或凭据。没有私有素材也能运行明确标注的占位版风险流程，不能把它当真实模型验收。

## 正式提交仍需完成

1. 本人确认适用的账号/套餐条款、参考图及原/派生模型与画面的公开展示/再分发范围。
2. 本人核实实际报名表、团队、作品声明和最终生效方式；当前没有正式回执。
3. 明确获准托管入口、责任人，完成匿名HTTPS、另一网络、目标设备与同版性能检查。
4. 将最终获准的报告、视频和实际体验绑定同一验收版本，再填写正式manifest并运行预检。

`submission-manifest.json`保留DRAFT和空的正式附件/验收/回执字段。当前`python scripts/check_submission.py`应为BLOCKED（退出2），不会用私有文件链接、假公网入口或代填本人声明来消除门禁。
