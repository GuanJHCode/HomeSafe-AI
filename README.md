## 技术方向

- Python 后端；Vue 3、TypeScript、Three.js 前端。
- Lux3D 用于核心三维资产或关键创作流程；先完成手动导入，再考虑在线生成。
- 规则采用明确、可解释的检查逻辑；运行时不依赖编程助手，不额外引入通用大模型。
- 首版检查空间关系与指定通道占用；完整人体可达性和导航不属于首版承诺。
